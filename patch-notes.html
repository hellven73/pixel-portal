Patch notes

Installable arcade, Console Mode and PixelWrapped

27 November 2026

Install PixelArcade from a supported browser. Browse Console Mode with the keyboard or a compatible controller, optionally adapt colours to cover art, and build a recap from sessions recorded in this browser. Game Tabs lets you reopen recent games while keeping only one game running.

Find your next game faster

26 November 2026

Press Ctrl+K or Cmd+K to search games and shortcuts. Use Game Roulette to discover games by category, or Continue Playing to reopen recent games on this browser. An individual game may keep its own progress.

Offline game downloads

26 November 2026

Download Hextris from the Game Library or the Quake II engine from Webported Games. Quake II requires your own game data and a local server. CloudMoon still requires internet access.

Smoother homepage and game browsing

26 November 2026

Game cards now tilt and follow your cursor, and search results move smoothly as you filter the library. Artwork carries into the game player when supported. The original PixelArcade design is intact, and the new effects respect your reduced-motion preference.
