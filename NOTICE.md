# Credits and source

Pixel Portal application code is a new implementation. It is not the original server source of eiym.org and is not affiliated with that service.

The game catalogue snapshot contains publicly served titles, source identifiers, image links and launch links from eiym.org. The referenced games and artwork remain on their existing hosts; no game binaries, ROMs, artwork packs or the reference site's application bundles are included. Hosting rights for those assets are not granted by this application's license. Runtime availability depends on those external hosts.

The isolated browser uses Mercury Workshop's open-source Scramjet 1.1.0, Bare-Mux 2.1.9, Libcurl Transport 1.5.2 and Wisp-JS 0.4.1. Their code and licenses are installed as npm dependencies. Scramjet is MIT-licensed; Wisp-JS and Libcurl Transport are AGPL-3.0-licensed. Consult each package's LICENSE for its exact terms. The service-worker integration follows Scramjet's documented public APIs.

The Pixel Portal application source is provided under AGPL-3.0; see LICENSE. Original CSS illustrations, UI and game engines from the first Pixel Portal version are retained where applicable.
